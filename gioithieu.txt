🎯 TỔNG QUAN HỆ THỐNG

Hệ thống Cinema Booking là một ứng dụng desktop được xây dựng theo mô hình 
Client-Server, cho phép người dùng đặt vé xem phim trực tuyến một cách 
nhanh chóng và tiện lợi. Dự án tập trung vào việc triển khai các khái niệm 
lập trình mạng, giao tiếp TCP/IP, xử lý đa luồng và quản lý cơ sở dữ liệu.

🔧 CÔNG NGHỆ SỬ DỤNG

▸ Ngôn ngữ lập trình: Java SE 17+
  • Lập trình hướng đối tượng (OOP)
  • Đa luồng (Multithreading) cho xử lý đồng thời
  • Socket Programming (TCP/IP) cho giao tiếp mạng
  • JDBC cho kết nối cơ sở dữ liệu

▸ Giao diện người dùng: Java Swing
  • JFrame, JPanel cho cấu trúc giao diện
  • JButton, JTable, JTextField cho tương tác
  • Event Handling (ActionListener, MouseListener)
  • Custom UI Components (SeatButton, MoviePanel)

▸ Cơ sở dữ liệu: MySQL 8+
  • 8 bảng chính: Users, Movies, Shows, Bookings, Combos, Promotions...
  • Foreign Key, Unique Constraint để đảm bảo tính toàn vẹn
  • Transaction handling cho xử lý đặt vé an toàn

▸ Thư viện bổ sung:
  • ZXing: Tạo mã QR cho vé điện tử
  • Apache Maven: Quản lý dependencies
  • VLCJ: Phát video trailer phim

🏗️ KIẾN TRÚC HỆ THỐNG

[CLIENT] ←──TCP Socket (Port 12345)──→ [SERVER] ←──JDBC──→ [MySQL DB]
   ↓                                        ↓                    ↓
Java Swing GUI                    Multithreading         8 bảng dữ liệu
Event Handling                    Business Logic          + Constraints
Socket Client                     Connection Pool         + Transactions

• Client: Giao diện đồ họa, xử lý input, hiển thị kết quả
• Server: Xử lý logic nghiệp vụ, quản lý kết nối, truy vấn database
• Database: Lưu trữ dữ liệu phim, vé, user, khuyến mãi...

🎯 ĐIỂM NỔI BẬT

▸ Xử lý đa luồng: Server có thể phục vụ nhiều client cùng lúc
▸ Đồng bộ hóa dữ liệu: Tránh xung đột khi nhiều người đặt cùng ghế
▸ Giao diện trực quan: Dễ sử dụng, responsive, có animation
▸ Bảo mật: Mã hóa mật khẩu, PreparedStatement chống SQL Injection
▸ QR Code: Vé điện tử hiện đại, dễ quét và xác thực
▸ Real-time: Cập nhật trạng thái ghế ngay lập tức
▸ Transaction: Đảm bảo tính toàn vẹn dữ liệu khi đặt vé

🚀 HƯỚNG DẪN CHẠY NHANH

1. Cài đặt: JDK 17+, MySQL 8+, Maven
2. Tạo database: Chạy file sql.sql
3. Cấu hình: Sửa thông tin DB trong MovieServer.java
4. Build: mvn clean install
5. Chạy Server: Run MovieServer.java
6. Chạy Client: Run MovieClient.java

💡 KẾT LUẬN

Dự án Cinema Booking System thể hiện sự kết hợp giữa lý thuyết và thực hành 
trong lập trình mạng. Hệ thống không chỉ minh họa các khái niệm về Socket 
Programming, Multithreading, Database Management mà còn có thể ứng dụng 
thực tế cho các rạp chiếu phim hoặc mở rộng cho các hệ thống đặt vé khác.

Thông qua dự án, nhóm đã nắm vững:
• Thiết kế và triển khai kiến trúc Client-Server
• Xử lý đồng thời với đa luồng
• Quản lý kết nối mạng TCP/IP
• Tích hợp cơ sở dữ liệu với ứng dụng Java
• Xây dựng giao diện người dùng với Swing
• Xử lý các vấn đề về đồng bộ hóa và bảo mật
